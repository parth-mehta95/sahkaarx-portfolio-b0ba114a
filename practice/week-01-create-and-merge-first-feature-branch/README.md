# Create and Merge First Feature Branch

## Task Brief
Create feature branch, make changes, open PR, review, and merge to main via pull request.

## Scenario
Add a basic API endpoint. Use feature branch, PR review workflow, and merge to main.

## Deliverables
- Feature branch with code changes
- Pull request with description
- Merged commit on main

## Success Criteria
- PR includes clear description
- Changes reviewed before merge
- Feature branch deleted after merge
